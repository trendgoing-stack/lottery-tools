# 抽選ツール

サイコロ・ルーレット・あみだくじ・チーム分けなど、「決める」「選ぶ」ときに使える道具をひとつにまとめたWebアプリです。
メンバーの名前を一度登録しておけば、どの機能でもそのまま使い回せます。

**▶ アプリを開く: https://trendgoing-stack.github.io/lottery-tools/**

登録やログインは不要です。無料で使えます。

## できること

- **メンバー管理** — 名前を登録すると全部の機能で使えます。「家族」「職場」「サークル」のようにグループを複数作って切り替えられます（作成・名前変更・複製・削除）。改行区切りでまとめて貼り付けることもできます
  - **今回参加** — メンバーごとのスイッチで、欠席の人を一時的に外せます
  - **リーダー** — ★を付けた人は、チーム分けで各チームに分かれて入ります
  - どの画面でも、上部のグループ名をタップすると、グループの切り替えと参加のON/OFFができます
- **サイコロ** — 1〜10個、面数は4・6・8・10・12・20・100・任意から選べます。6面は立体のサイコロが転がります。出目と合計、最近の履歴を表示します
- **ルーレット** — 項目を自由に追加・編集でき、項目ごとに「重み」（1〜10）を付けると、その分だけ当たりやすくなります。「当たった項目を次回から除外」や、項目セットの保存・呼び出しもできます
- **あみだくじ** — 参加メンバー（または本数を指定）で作ります。下の結果は「当たり」「1位〜」などをまとめて入力できます。名前をタップすると線をたどって結果がわかります。「全員一気に結果を見る」も使えます
- **チーム分け** — 「1チームの人数」か「チーム数」を指定します。人数が割り切れないときは均等に振り分けます。次の条件も付けられます
  - リーダーを各チームに分散する
  - 指定した2人を別々のチームにする（NGペア）
  - 前回と同じ組み合わせをなるべく避ける
- **その他**
  - **順番決め** — 参加メンバーの順番を、1位から順に発表します
  - **じゃんけん** — 参加メンバー全員で同時にじゃんけんします。あいこは自動で再戦し、最後の1人が決まるまで表示します
  - **くじ引き** — 当たりの本数を決めて、1人ずつ自分の名前をタップして引きます
  - **コイントス** — 表か裏か。これまでの回数と割合も表示します

### どの機能でも使えること

- **全画面** — 結果を大きな文字で画面いっぱいに表示します。みんなに画面を見せたいときに便利です
- **共有** — 結果をLINEやメールなどに送れます（共有できない環境ではコピーします）
- **効果音** — 画面右上のスピーカーのボタンでオン・オフできます
- **演出スキップ** — ⚙（設定）でオンにすると、アニメーションを省いてすぐに結果を表示します
- 演出の途中で画面が暗くならないようにしています（対応している端末のみ）

## iPhoneで使う

ホーム画面に追加すると、アプリのように全画面で使えます。一度開けば、電波のない場所でも起動します。

1. **Safari** で上のリンクを開く
2. 画面下の共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」をタップ

> [!IMPORTANT]
> Safariで開いた場合とホーム画面から開いた場合では、メンバーや設定が**別々に保存**されます。
> 普段使うときは、ホーム画面のアイコンから開くようにしてください。

AndroidやPCでも、ChromeやEdgeなどのブラウザで同じように使えます。

## アプリの更新

新しいバージョンが用意できると、アプリを開いたときに画面の上部に
**「更新があります（タップで再読み込み）」** と表示されます。
タップすると最新版に切り替わります。表示されないときは、すでに最新版です。

いま使っているバージョンは、⚙（設定）のいちばん下で確認できます。

## データについて

- メンバー・グループ・保存した項目・設定は**お使いの端末の中だけ**に保存されます。サーバーには送信されないので、ほかの人に見られることはありません
- そのため、**機種変更やブラウザのデータ削除をするとデータは消えます**
- ⚙（設定）の「すべてのデータを消す」で、このアプリのデータだけをまとめて消せます
- アクセス数の計測に [GoatCounter](https://www.goatcounter.com/) を使っています。記録されるのは「どのページが何回開かれたか」だけで、クッキーは使わず、メンバー名などアプリの中身が送られることはありません

## 公平さについて

- 乱数には、ブラウザの暗号用の乱数（`crypto.getRandomValues`）を使い、特定の数が出やすくならない方法で整数を作っています
- ルーレット・サイコロ・コイントスなどは、**ボタンを押した瞬間に結果が決まり**、アニメーションはその結果に向かって止まるだけです。演出の長さや止まり方で結果が変わることはありません
- あみだくじは、下の結果の並びをくじを作るときにシャッフルしているので、どの線を選んでも有利・不利が出にくくなっています
